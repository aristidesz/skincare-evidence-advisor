# Streamlit Chat

Built with ❤️ by [aristidesz](https://github.com/aristidesz)


This repository serves as a template for hosting a Streamlit dashboard on AWS. It is designed to be used as the front end for a Large Language Model (LLM) chatbot. The specific usage of the LLM is yet to be decided.

## Features

- Streamlit-based front end
- Pre-configured for deployment on AWS
- Includes linting, testing, and formatting tools

## Getting Started

### Prerequisites

- Python 3.9
- pip
- virtualenv

### Installation

1. Clone the repository:

    ```sh
    git clone https://github.com/aristidesz/streamlit_chat.git
    cd streamlit_chat
    ```
